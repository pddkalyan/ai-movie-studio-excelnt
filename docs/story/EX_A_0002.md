## Scope / evidence

Immutable MovieBible character profiles bind globally unique character IDs, role IDs and voice IDs to content-hashed versioned visual references. Each character has a canonical costume and allowed prop IDs. Location profiles likewise bind a versioned hashed reference.

StoryPlan is frozen to a specific Bible revision **and entire Bible content digest**, rejecting silent edits at the same revision. It must have exactly 1,200 seconds at 24fps, a 16:9 frame, contiguous ordered shots, and no shot longer than 15 seconds. A deterministic 12-scene/120-shot fixture validates 28,800 **planned** frames, but it contains no generated film.

Across all scenes, validation rejects changes to character reference asset/version/checksum, voice identity, costume, unknown prop, scene location reference, duplicate role/scene/shot/line IDs, invisible speaker, gaps, overlaps, wrong scene order, stale Bible, malformed IDs or invalid Unicode. Unicode screenplay dialogue is accepted after validation.

The story receipt journal uses a strict schema, monotonic sequence, prior SHA-256 chain, atomic file writes with fsync, and exclusive non-expiring task lock. An exact replay is idempotent; a conflicting replay, corrupted file, change of frozen Bible/plan or orphaned lock is **blocked without silently replacing prior checkpoint bytes**. A checkpoint is not proof of media output or of external inference. Runtime state should stay in a private directory excluded from Git.
