# Product acceptance matrix — Excelnt Edition

These are target requirements, NOT proof completed.

| ID | Goal | Required independent verification |
|---|---|---|
| EX-R01 | Stable Movie Bible characters/voices | Reference versioning, voice binding, across-shot visual continuity |
| EX-R02 | Engaging 20-minute screenplay | Scene arc, written continuity and story review |
| EX-R03 | Exactly 1200s 16:9 output | Real media metadata, 24fps frame-contiguous completed movie, audio |
| EX-R04 | Provider-neutral cloud video | Replaceable T2V/I2V/V2V/motion adapters and genuine receipts |
| EX-R05 | Character consistency | Face, clothing, props, location evidence and revision matching |
| EX-R06 | Multi-character lip sync/SFX | Measured audio/video sync, speaker-specific voice references |
| EX-R07 | Timeline & post-production | No gaps/overlaps, approved asset versions, QC of exact render |
| EX-R08 | Crash/replay safety | Atomic checkpoints, lease, corrupt/restart/retry negative cases |
| EX-R09 | Zero paid use | Authenticated 5h/week feed and **provider-enforced no balance fallback** |
| EX-R10 | Drive archive verification | Actual checksum readback, owner authorization, cleanup evidence |
| EX-R11 | Provenance & secret safety | Exact source SHA, creator/model, no private logs/secrets |
| EX-R12 | Final reviewer gate | Genuine independently authenticated review of exact candidate SHA |

Phase 0 only tests **structural portions** of EX-R01/03/04/08/09. Does not prove genuine video, voices, lip sync, provider identity or Drive uploads.

Phase 1: narrative/asset contracts; Phase 2: balance-safe documented provider and official quota adapter; Phase 3: authorized real cloud generations and technical QC; Phase 4: assembly, archive and complete episode verification. No guaranteed unlimited render claims.
